Kompres PDF Online

Kurangi ukuran PDF dengan mengoptimalkan tampilan setiap halaman menjadi gambar JPEG, lalu menyusunnya kembali sebagai PDF.

Pilih PDF lalu tekan Kompres PDF. Tunggu sampai proses selesai sebelum menutup halaman.

Cara kompres PDF

  1. Pilih satu file PDF dari HP atau komputer.
  2. Pilih kualitas Tinggi, Seimbang, atau Kecil.
  3. Tekan tombol Kompres PDF dan tunggu proses selesai.
  4. File hasil akan diunduh dengan nama kompres-chanstore.pdf.

Catatan penting tentang kualitas

Alat ini membuat ulang setiap halaman sebagai gambar. Karena itu, teks dalam PDF hasil tidak bisa dipilih atau dicari seperti teks PDF asli. Dokumen yang berisi teks kecil, tabel, atau gambar detail dapat terlihat kurang tajam, terutama pada pilihan Kecil. Hasil akhir bisa saja lebih besar dari file asli jika PDF sumber sudah sangat teroptimasi.

Privasi dan batas penggunaan

Pemrosesan dilakukan di browser perangkat kamu; file tidak dikirim ke server ChanStore. File PDF yang sangat besar atau memiliki banyak halaman mungkin kehabisan memori pada HP. Coba file yang lebih kecil jika proses gagal.

Tentang Kompres PDF Online Gratis

Kurangi ukuran PDF dengan merender halaman menjadi gambar lalu menyusun kembali gambar tersebut menjadi PDF. Metode ini dapat mengecilkan dokumen tertentu, tetapi mengubah sifat teks dan elemen halaman.

Cara menggunakan

  1. Pilih file PDF, tentukan kualitas hasil, lalu jalankan proses kompresi. Unduh file baru setelah proses selesai.
  2. Periksa kembali input dan pengaturan sebelum menjalankan alat.
  3. Simpan atau unduh hasil, lalu periksa apakah sudah sesuai kebutuhan.

Kegunaan dan tips

Cocok untuk dokumen hasil scan yang lebih mengutamakan ukuran file daripada teks yang dapat diseleksi. Simpan file asli sebagai cadangan.

Batasan yang perlu diketahui

Karena halaman dirender menjadi gambar, teks PDF hasil mungkin tidak bisa diseleksi atau dicari. Kualitas rendah dapat membuat tulisan kurang jelas. File besar memerlukan memori lebih banyak.

Pertanyaan umum

Apakah teks di PDF hasil tetap bisa diseleksi?

Tidak dijamin. Metode kompresi ini merender halaman menjadi gambar sehingga teks dapat berubah menjadi konten gambar.
