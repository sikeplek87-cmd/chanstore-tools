Kebijakan Privasi

ChanStore Tools tidak meminta pengguna membuat akun. Beberapa alat memproses file langsung di browser. Jika kelak iklan atau analitik pihak ketiga dipasang, penyedia tersebut dapat menggunakan cookie atau teknologi serupa sesuai kebijakan mereka. Hubungi kami untuk pertanyaan privasi.
