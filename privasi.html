Kebijakan Privasi

Terakhir diperbarui: 4 November 2026.

1. Informasi Umum

ChanStore Tools menyediakan berbagai alat online gratis. Kami berupaya menjaga privasi pengguna dan tidak mewajibkan pembuatan akun untuk menggunakan layanan.

2. Pemrosesan File dan Data

Beberapa alat memproses file langsung di browser pengguna. File tersebut tidak perlu diunggah ke server kami untuk pemrosesan yang dilakukan sepenuhnya di browser. Namun, cara kerja setiap alat dapat berbeda.

3. Layanan Pihak Ketiga

Fitur QR Code menggunakan layanan QR pihak ketiga untuk menghasilkan gambar QR. Teks yang dimasukkan pada fitur tersebut dapat dikirim ke penyedia layanan tersebut. Penggunaan layanan pihak ketiga tunduk pada kebijakan privasi masing-masing penyedia. Hindari memasukkan kata sandi, informasi keuangan, atau data rahasia lainnya.

4. Cookie dan Teknologi Serupa

Website dapat menggunakan cookie atau teknologi serupa apabila layanan analitik, iklan, atau fitur pihak ketiga diterapkan. Teknologi tersebut dapat digunakan untuk mengukur penggunaan layanan dan menampilkan iklan sesuai kebijakan penyedia terkait.

5. Iklan

Jika iklan pihak ketiga, termasuk Google AdSense, diterapkan pada website ini, penyedia iklan dapat menggunakan cookie atau teknologi serupa untuk menampilkan, mengukur, dan mempersonalisasi iklan sesuai pengaturan dan kebijakan privasi mereka.

6. Keamanan dan Penyimpanan Data

Kami tidak meminta pengguna membuat akun. Kami tidak bermaksud mengumpulkan atau menyimpan file yang diproses secara lokal oleh browser. Namun, komunikasi dengan layanan pihak ketiga dan infrastruktur website tetap tunduk pada kebijakan penyedia masing-masing.

7. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu apabila terdapat perubahan fitur, layanan, atau ketentuan yang berlaku. Perubahan akan dipublikasikan pada halaman ini.
